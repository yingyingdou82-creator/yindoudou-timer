# 🫘 银豆豆计时

一款简洁可爱的多端日期倒计时 / 正计时工具，帮您记住生活中每一个重要的日子。
支持 **Windows 电脑** 和 **安卓手机**，两边都有**桌面小组件**，抬眼就能看到"还有几天"。

![主窗口](docs/screenshots/main-window.png)

## ✨ 功能特性

### 事件管理
- 创建 / 编辑 / 删除 / 置顶 / 搜索事件
- 每条事件可配置：名称、日期、颜色标签（8 色）、emoji 图标、备注
- **背景图片**：四种方式添加（按钮选择 / 拖拽文件 / Ctrl+V 粘贴截图 / 从网页拖图），自动压缩，作为卡片背景显示
- **归档**：完成的事件一键归档，主界面清爽，随时可找回、恢复、删除

### 计时能力
- **方向自动判断**：过去的日期自动按正计时（"已经 100 天"），未来的按倒计时（"还有 88 天"），今天显示"就是今天！"
- **四种计数方式**：自然日 / 工作日 / 按周 / 按年（如"还有 1 年 2 个月 3 周 4 天"）
- **工作日可叠加中国法定节假日**：内置 2025 / 2026 年国务院官方安排（含调休补班）
- **包含起始日开关**：起算第一天算不算，您说了算
- **时间段事件**：填一个日期段（比赛期、报名期），显示自动切换——「距离开始还有 X 天」→「距离截止还有 X 天」→「已结束 X 天」
- **具体时间**：比赛、报名填上几点几分，当天精确显示"还有 2 小时 15 分钟"
- **到点提醒**：提前 5 分钟 ~ 1 天系统通知（电脑版 + 安卓版；安卓在 App 关闭时也能收到）

### 桌面小组件
- **电脑**：悬浮豆荚面板，勾选哪些事件上桌面，高度随条数自动伸缩；可拖动并记住位置，宽度三档、透明度三档
- **安卓**：系统级桌面小部件（长按桌面添加），最多显示 5 条，天数自动更新

### 外观与系统
- 深色 / 浅色主题，电脑、手机、小组件三端同步
- 字体大小四档（小 / 标准 / 大 / 特大）
- 电脑版：自绘标题栏、系统托盘常驻、可选开机自启
- **数据全在本地**，不上传云端；支持导出 / 导入备份（事件 + 图片打包成一个文件，可合并可替换）

## 🚀 下载安装

安装包在项目 `release/` 目录下本地构建（也可从作者处获取）：

- **Windows**：`银豆豆计时 Setup x.x.x.exe` — 双击安装，自动创建快捷方式
- **Android**：`银豆豆计时-安卓版.apk` — 下载后点开安装（允许"未知来源"即可）

> 电脑版数据存在 `C:\Users\用户名\AppData\Roaming\yin-dou-dou-timer\`，安卓版存在应用私有目录，均可通过"导出备份"迁移。

## 🛠 开发指南

```bash
npm install          # 安装依赖

# 电脑版（Electron）
npm run dev          # 开发模式
npm run dist         # 打 Windows 安装包（产物在 release/）

# 网页 / 安卓版
npm run dev:web      # 网页版开发服务器（可手机局域网访问）
npm run build:web    # 构建网页版（dist-web/）

# 安卓（首次需配好 JDK 21 与 Android SDK，见 CLAUDE.md 备忘）
npx cap sync android
cd android && JAVA_HOME=/d/android-tools/jdk-21 ANDROID_HOME='D:\android-sdk' ./gradlew assembleDebug
# 产物：android/app/build/outputs/apk/debug/app-debug.apk
```

### 技术栈

| 层 | 技术 |
|---|---|
| 电脑版外壳 | Electron 44 |
| 界面 | Vue 3 + TypeScript + Element Plus |
| 构建 | electron-vite（电脑）/ Vite（网页安卓） |
| 安卓 | Capacitor 8（含原生桌面小部件） |
| 数据 | 本地 JSON（电脑）/ IndexedDB（手机） |

### 目录结构

```
├── src/
│   ├── main/        # Electron 主进程（窗口、托盘、存储、提醒）
│   ├── preload/     # 安全传话层
│   ├── renderer/    # 界面（主窗口 + 桌面小组件页面 + 平台适配层）
│   └── shared/      # 双端共用（类型、校验、节假日数据）
├── android/         # 安卓工程（Capacitor + 原生小部件）
├── scripts/         # 图标生成、截图等工具脚本
└── docs/            # 文档与截图
```
